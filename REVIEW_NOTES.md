# App Review Notes

Paste into App Store Connect → App Review Information → Notes.

Sidenote is a local-only notes app. There is no account, no sign-in, no in-app purchases, no ads, and no remote server. Nothing is gated by region, time, account type, or review environment. The binary under review is the full product.

## How to test

1. **Create a note**
   - Tap the capture prompt on the home screen.
   - Type a short note.
   - Tap **Done**.
   - A tip appears: swipe up to see earlier sidenotes.

2. **Go Live (Live Activity)**
   - After dismissing the scroll tip (or swiping up), a tip explains Go Live.
   - **Long-press** a note.
   - Tap **Go Live**.
   - Lock the phone (or glance at Dynamic Island on supported devices) to see the Live Activity.
   - Long-press the same note again and tap **Stop Live** to end it.
   - Appearance options: Settings (⋯) → **Live Activity**.

3. **Home Screen widget**
   - Long-press the Home Screen → Edit → Add Widget → search **Sidenote** → Add.
   - In-app steps: Settings → **Widget**.

4. **Other note actions**
   - Long-press a note for **Edit**, **Share**, or **Remove**.
   - Recently removed notes: ⋯ menu → **Recently Removed** (kept on device for 30 days).

## Guideline 5.6 clarification

No features are intentionally hidden, dormant, or switched after approval. Live Activities and the widget are documented first-class features. A one-time TipKit tip appears after the first note explaining Go Live. Settings → About Sidenote also lists how to reach every feature. All features work offline with no network required.
